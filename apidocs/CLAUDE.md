apidocs/ contains four directories:
- **vsapi**: The official Vintage Story API (615 files). Three-tier architecture with Client, Server, and Common layers. Provides ICoreAPI interfaces, entity systems, inventory management, block/item classes, crafting recipes, world access, event systems, networking, math utilities, and data structures. This is the foundation all mods build on.
- **vsessentialsmod**: Shared game systems (206 files) used by both survival and creative modes. Includes entity behaviors (health, hunger, AI, pathfinding with GOAP), block behaviors (multiblock, decoration), asset loaders for blocks/items/entities, weather simulation, world map rendering, room detection, entity partitioning, and cloth physics. Entry point: Core.cs.
- **vssurvivalmod**: Complete survival mode implementation (927 files). Contains 163 block types, 68 items, 81 block entities, and 27 major gameplay systems including mechanical power networks, cooking/recipes, trading, dialogue trees, riding/mounts, boats, temporal rifts, dungeons, prospecting, and the handbook/journal. Excellent reference for API usage patterns and real-world implementation examples.
- **vscreativemod**: Creative mode with full WorldEdit system (30 files, 8.5k lines). Features 12 terrain editing tools (paint brush, air brush, select, move, import, line, eraser, erode, flood fill, raise/lower, grow/shrink, repeat), 40+ `/we` commands, schematic import/export, undo/redo, per-player workspaces, flat world generation, and the Magic Wand item. Far more capable than a basic item browser.

Always use an agent when exploring these.
